## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), compact pill padding (`px-2 py-1`), tight vertical label offsets (`mt-1`) |
| sm | 8px | Control row spacing (`gap-2`), header cluster gaps (`gap-2`), stacked form field offsets (`mt-2`) |
| md | 16px | Default card interior (`p-4` feed & sub-cards), form & 2-col grids (`gap-4`), vertical card groups (`space-y-4`) |
| lg | 24px | Page section cadence (`space-y-6`), modal containers (`p-6`), `<main>` top offset (`pt-6`) |
| xl | 32px | Page shell horizontal padding (`lg:px-8`) |
| 2xl | 48px | Empty-state interior padding (`p-12`) |
| 3xl | 64px | Page bottom clearance (`pb-16` in `src/app/layout.tsx`) |

Exceptions: `gap-5` (`20px`) and `p-5` (`20px`) are locked by `07-CONTEXT.md` (`D-01`, `D-02`) as the standard 4-column card grid gutter (`gap-5`) and primary module padding (`p-5`), alongside `gap-3` (`12px`), `space-y-3` (`12px`), and `pt-3` (`12px`) for compact 3-column Detour alternatives, feed card internal stacks, and footer dividers (all valid multiples of 4).
